# Pranav J Datta — Portfolio

A responsive, dark-first personal portfolio built with plain HTML, CSS, and JavaScript.

## Preview locally
1. Extract this folder.
2. Open `index.html` in your browser, or open the folder in VS Code and use Live Server if installed.

No framework, package manager, or build step is required.

## Publish free with GitHub Pages
1. Create a new GitHub repository (for example, `pranav-portfolio`).
2. Upload the contents of this folder, making sure `index.html` is at the repository root.
3. Open **Settings → Pages**.
4. Under build/deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. GitHub Pages will show the published URL once deployment completes.

## Before publishing
- Your requested email is displayed publicly. Remove it if you decide not to publish it openly.
- Replace generic GitHub links with your actual profile or project URL when ready.
- Confirm exact workshop title/date and MUN conference/award details if you want to list them.
- A résumé link can be added once a résumé PDF is ready; this version avoids linking to a nonexistent file.
- The page uses web fonts with system fallbacks and stores the portrait locally in `assets/pranav-speaking.png`.

## Editing
- `index.html` — text, sections, and links
- `styles.css` — layout, colors, and responsive styling
- `script.js` — mobile navigation and current year
